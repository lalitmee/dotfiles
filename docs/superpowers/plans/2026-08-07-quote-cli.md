# Offline Quote CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a local, offline terminal quote CLI in `~/.config/bin/quote` that displays a daily rotated category quote when starting interactive shells.

**Architecture:** Use modular flat text files for the categories databases under `bin/.config/bin/quotes/`. Use day of the year (`date +%j`) modulo division in Zsh to determine today's theme, select a random line using `shuf`, split on ` | ` separator, and render with custom styling using the existing `gum_style` helper.

**Tech Stack:** Zsh, `gum`, `shuf`, standard GNU coreutils.

## Global Constraints

* Fully Offline: Display inspiring quotes without querying any remote API on terminal startup.
* Offline Categories: Keep files inside `bin/.config/bin/quotes/`.
* Date Formatting: Zsh array indices must parse the day of the year as a base-10 integer: `$(( 10#$(date +%j) ))` to prevent octal errors.
* Error Handling: Exit silently with code 0 on shell startup if any database file or the `quotes/` folder is missing.
* Shell Startup Hook: Wrap the invocation in `zsh/.zshrc` inside `[[ -o interactive ]]` and verify `quote` exists in command path.

### Task 2: Implement quote executable

**Files:**
* Modify: `bin/.config/bin/quote`

**Interfaces:**
* Consumes: Category database files in `bin/.config/bin/quotes/`
* Produces: A script that prints quotes using `gum_style` with support for daily rotation or manual overrides.

- [ ] **Step 1: Replace content of `bin/.config/bin/quote`**
  Write the following Zsh script to [bin/.config/bin/quote](file:///home/lalitmee/dotfiles/bin/.config/bin/quote):
  ```zsh
  #!/usr/bin/env zsh

  # --- Check if gum is installed ---
  if ! command -v gum &> /dev/null; then
      echo "Error: gum is not installed." >&2
      echo "Please install it: https://github.com/charmbracelet/gum" >&2
      exit 1
  fi

  # --- Configuration ---
  SCRIPT_DIR="${0:A:h}"
  QUOTES_DIR="$SCRIPT_DIR/quotes"
  QUOTE_COLOR="#FFC600"
  AUTHOR_COLOR="#EE80E1"

  # Print usage instructions
  show_help() {
      cat << EOF
  Usage: quote [options] [category]

  An offline quote generator featuring daily rotated categories.

  Options:
    -l, --list      List all available categories
    -h, --help      Show this help message

  Categories:
    confidence, humor, learning, motivation,
    philosophy, programming, productivity, wisdom
  EOF
  }

  # List all available categories
  list_categories() {
      if [[ ! -d "$QUOTES_DIR" ]]; then
          echo "No categories database folder found at $QUOTES_DIR"
          return 1
      fi
      for f in "$QUOTES_DIR"/*.txt; do
          if [[ -f "$f" ]]; then
              basename "$f" .txt
          fi
      done
  }

  # Render quote from a file
  show_quote_from_file() {
      local file_path="$1"
      local startup_mode="$2"

      if [[ ! -f "$file_path" ]]; then
          if [[ "$startup_mode" != "true" ]]; then
              echo "Error: Category file not found at $file_path" >&2
          fi
          return 1
      fi

      # Read a random line from the file using shuf
      local selected_line
      selected_line=$(shuf -n 1 "$file_path" 2>/dev/null)
      
      if [[ -z "$selected_line" ]]; then
          if [[ "$startup_mode" != "true" ]]; then
              echo "Error: Category file is empty." >&2
          fi
          return 1
      fi

      # Split on ' | ' delimiter
      # Zsh parameter expansion to split string into parts
      local parts
      parts=("${(s: | :)selected_line}")
      local quote="${parts[1]}"
      local author="${parts[2]}"

      if [[ -n "$quote" && -n "$author" ]]; then
          local quote_string="$quote -- $author"
          # Sourcing gum_style directly if it's in the PATH, or execute as command
          if command -v gum_style &>/dev/null; then
              gum_style "$quote_string" "$QUOTE_COLOR" "$AUTHOR_COLOR"
          else
              # Fallback style if gum_style is unavailable
              gum style --foreground "$QUOTE_COLOR" --border rounded --align center --padding "1 2" "$quote"$'\n\n'"-- $author"
          fi
      fi
  }

  # --- Main Execution ---

  # Check if quotes directory is missing on startup
  if [[ ! -d "$QUOTES_DIR" ]]; then
      # Silent exit if it's startup, error message if run explicitly
      if [[ $# -eq 0 ]]; then
          exit 0
      fi
  fi

  if [[ $# -eq 0 ]]; then
      # Daily Rotation Mode
      local categories
      categories=($(list_categories | sort))
      local num_categories=${#categories[@]}

      if [[ $num_categories -eq 0 ]]; then
          exit 0
      fi

      # Determine today's category using day of the year
      local day_of_year=$(( 10#$(date +%j) ))
      local index=$(( (day_of_year % num_categories) + 1 ))
      local active_category="${categories[$index]}"
      
      show_quote_from_file "$QUOTES_DIR/${active_category}.txt" "true"
  else
      # Parsing arguments
      case "$1" in
          -h|--help)
              show_help
              exit 0
              ;;
          -l|--list)
              list_categories
              exit 0
              ;;
          *)
              # Show quote for requested category
              local requested_category="$1"
              show_quote_from_file "$QUOTES_DIR/${requested_category}.txt" "false"
              ;;
      esac
  fi
  ```
