Each `.mcp.json` sibling is a JSON array to pass as the `elements` string to `create_view`. It includes the skeleton `start`/`end` references required by the tested converter. Native files instead persist endpoint bindings and reciprocal references. Each `.svg` is a schematic generated by the Python builder; `.rendered.svg` and `.rendered.png` use the actual Excalidraw renderer. Refresh renderer exports after rebuilding changed geometry.

## Verification observation — 2026-11-25

- Five fresh-context no-skill controls and five guided agent cases exercised styling consistency, uncertain retry semantics, decisions, architecture and attachment reporting. Guided cases retrieved the exact shared tokens and distinguished unverified behavior; adapter refinements received follow-up tests.
- The native scenes passed static validation and seven negative mutation checks: absent start/end binding, zero gap, dangling ID, missing reciprocal reference, detached endpoint and overlapping shapes.
- All 15 connected shapes across the three pilots were independently moved horizontally and vertically, resized, serialized/restored, and moved again in a local Excalidraw 0.18.0 editor using canvas pointer events. Endpoint geometry and binding identities were checked after resizing and reopening.
- The same tests passed for all 15 shapes after converting the `.mcp.json` inputs with the installed MCP's Excalidraw converter. This tests the conversion path as well as the native files.
- Actual renderer exports were visually inspected for all three native pilots. The approval payload was also accepted by the connected `create_view` MCP tool and displayed successfully.

These checks cover the installed version and the tested movements. The ordinary multipoint arrows remain connected but are not native auto-routing elbow arrows; moving nodes can change segment angles. Review routing after large layout changes. The skill distinguishes static, visual and behavior checks so a future agent cannot infer a successful movement test from a screenshot.

## Reproduce static checks

From the skill directory:

```zsh
python3 scripts/validate_scene.py --self-test
python3 scripts/validate_scene.py examples/*.excalidraw
```

For editor checks, follow [the checklist](../references/review-checklist.md). The temporary local test harness and raw session output are not runtime dependencies of this skill.
